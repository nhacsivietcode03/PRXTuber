Hướng Dẫn Kiểm Thử Hot Update (OTA) Trên Simulator

Cẩm nang kỹ thuật chi tiết giúp bạn hiểu rõ cơ chế nạp bundle, quy trình build Release trên iOS Simulator, triển khai bản vá qua Cloudflare và kiểm tra cập nhật tức thì.

1 Tổng Quan Kiến Trúc Hot Updater trong PRXTuber

Hệ thống Hot Update (Over-The-Air) cho phép cập nhật giao diện, logic JavaScript và tài nguyên mà không cần thông qua App Store hoặc Google Play review.

1. Lập Trình Viên

Thực hiện sửa lỗi hoặc cập nhật tính năng trong code React Native.

2. Đóng Gói & Ký Số

CLI tạo bundle JS, assets và ký điện tử RSA bằng keys/private-key.pem.

3. Cloudflare D1 + R2

Lưu siêu dữ liệu phiên bản trên D1 và file nén bundle trên R2 Storage.

4. Simulator / Thiết Bị

Tải bundle, xác thực chữ ký bằng public-key.pem và nạp lại app.

2 Cốt Lõi: Vì Sao Phải Dùng Bản Release Trên Simulator?

Nhiều lập trình viên gặp tình huống: Đã deploy bản hot update mới, app thông báo tải thành công nhưng khi khởi động lại thì giao diện vẫn không đổi. Lý do bắt nguồn từ đoạn mã gốc trong AppDelegate.swift:

ios/PrxTuber/AppDelegate.swift (Dòng 64 - 70) 
override func bundleURL() -> URL? {
#if DEBUG
    // Chế độ DEBUG: Luôn tải bundle trực tiếp từ Metro Dev Server (cổng 8081)
    return RCTBundleURLProvider.sharedSettings().jsBundleURL(forBundleRoot: ".expo/.virtual-metro-entry")
#else
    // Chế độ RELEASE: Đọc bundle offline do HotUpdater quản lý trong sandbox đĩa
    return HotUpdater.bundleURL()
#endif
}
Tiêu chí so sánh Chế độ Debug (Mặc định) Chế độ Release (Khuyên dùng test OTA)
Lệnh khởi chạy npx expo run:ios npx expo run:ios --configuration Release
Nguồn đọc Bundle JS Metro Bundler (Live qua mạng) HotUpdater.bundleURL() (File cục bộ)
Hiệu lực Hot Update Bị Metro ghi đè khi reload Áp dụng 100% chính xác như thực tế
Fast Refresh (HMR) Có hỗ trợ Không (chỉ cập nhật qua OTA)
📌

Kết Luận Quan Trọng

Để kiểm tra trọn vẹn quy trình Tải bundle -> Lưu vào máy -> Reload đọc bundle mới, bạn cần build app ở chế độ Release trên Simulator!

3 Quy Trình Kiểm Thử Chuẩn Xác Từng Bước

1

Build & Cài Đặt Bản App Gốc (Release) Lên Simulator

Tắt tiến trình Metro bundler đang chạy (nếu có), sau đó mở Terminal tại thư mục gốc và chạy lệnh:

Terminal 
npx expo run:ios --configuration Release

Lệnh này biên dịch app với cấu hình Release, đóng gói sẵn mã JavaScript gốc vào file binary và cài trực tiếp lên iOS Simulator đang mở.

2

Tạo Thay Đổi Giao Diện Trong Mã Nguồn Để Nhận Biết

Mở file src/screens/SettingsScreen.js (hoặc bất kỳ màn hình nào) và thêm một dòng thông báo dễ nhận thấy:

src/screens/SettingsScreen.js 
// Thêm vào trước nút "Kiểm tra bản cập nhật" hoặc ở đầu trang:
<View style={{ backgroundColor: '#10B981', padding: 12, borderRadius: 8, marginVertical: 10 }}>
  <Text style={{ color: '#FFFFFF', fontWeight: 'bold', textAlign: 'center' }}>
    🎉 HOT UPDATE V2 TEST THÀNH CÔNG TRÊN SIMULATOR!
  </Text>
</View>
3

Đóng Gói & Deploy Bản Vá Lên Cloudflare Server

Bạn có thể sử dụng script tương tác có sẵn của PRXTuber:

Terminal 
npm run hot:deploy

Hoặc chạy trực tiếp bằng lệnh CLI với cờ Force Update (-f):

Terminal 
npx hot-updater deploy -p ios -c production -t 1.0.0 -m "Test Hot Update Simulator V2" -f
💡

Kiểm Tra Bundle Đã Lên Server Chưa

Chạy lệnh npm run hot:list để thấy bản bundle mới xuất hiện ở dòng đầu tiên với trạng thái Enabled: yes.

4

Kiểm Tra & Áp Dụng Bản Cập Nhật Trên Simulator

Có 2 cách kích hoạt cập nhật:

Cách A: Thủ công qua Màn hình Cài đặt

  1. Mở app trên iOS Simulator.
  2. Chuyển sang tab Cài đặt (Settings).
  3. Bấm vào mục "Kiểm tra bản cập nhật".
  4. App hiển thị popup thông báo có bản mới -> Bấm "Cập nhật ngay".
  5. Tải xong bấm "Khởi động lại" để áp dụng.

Cách B: Tự động khi Khởi động lại App

  1. Vuốt ứng dụng lên từ thanh Home Bar (hoặc bấm tổ hợp đa nhiệm) để tắt hẳn app.
  2. Mở lại app: Component HotUpdater.wrap sẽ tự động kiểm tra server.
  3. Màn hình HotUpdaterLoadingScreen sẽ hiện thanh tiến trình % tải về.
  4. App tự động tải xong và nạp lại giao diện mới tức thì!
🔍

Xác Nhận Cập Nhật Thành Công

Sau khi app nạp lại, bạn sẽ thấy banner màu xanh lá xuất hiện, đồng thời trong màn hình Settings, mã OTA Bundle ID ở dưới cùng đã đổi thành mã UUID của bản vá vừa deploy!

4 Checklist Thao Tác Nhanh Dành Cho Tester

Bạn có thể tích chọn các bước dưới đây để theo dõi tiến độ test:

  • Đã tắt server Metro bundler cũ (tránh xung đột cổng 8081).
  • Đã chạy lệnh npm run hot:doctor và toàn bộ mục kiểm tra đều PASS.
  • Đã build và cài đặt bản Release lên iOS Simulator (npx expo run:ios --configuration Release).
  • Đã mở app bản gốc và ghi nhớ giao diện ban đầu.
  • Đã sửa một chi tiết trong code và chạy lệnh deploy (npx hot-updater deploy -p ios -f).
  • Đã kiểm tra danh sách bundle trên server bằng npm run hot:list.
  • Đã mở lại app trên Simulator và thấy giao diện thay đổi kèm mã OTA Bundle ID mới.

5 Kiểm Thử Nhanh Trong Chế Độ DEBUG (__DEV__)

Nếu bạn chỉ muốn kiểm tra giao diện màn hình Loading, kiểm tra kết nối API Cloudflare Worker hoặc kiểm tra popup trong Settings mà không muốn mất thời gian build bản Release:

  1. Mở file src/config/hotUpdater.js:
    src/config/hotUpdater.js 
    export const HOT_UPDATER_CONFIG = {
  baseURL: "https://prxtuber-updater-worker.iop883684.workers.dev/api/check-update",
  updateStrategy: "appVersion",
  enableInDev: true, // 👈 Bật true để kích hoạt HotUpdater trong chế độ Debug
};
  2. Khởi chạy app như bình thường: npx expo run:ios.
  3. Vào tab Settings -> Bấm "Kiểm tra bản cập nhật" để test luồng gọi API và tải file zip.
⚠️

Lưu Ý Quan Trọng Khi Bật enableInDev

Trong chế độ Debug, do native code iOS luôn ưu tiên kết nối Metro, sau khi tải bundle về máy thì việc reload có thể vẫn nạp code từ Metro. Sau khi test xong API, hãy nhớ đặt enableInDev: false để không làm ảnh hưởng đến tính năng Fast Refresh khi code hàng ngày.

6 Bảng Tra Cứu Lệnh Vận Hành Nhanh

Mục đích Lệnh Terminal Ghi chú
Kiểm tra hệ thống npm run hot:doctor Kiểm tra toàn bộ Cloudflare Worker, D1, R2 và cấu hình iOS/Android.
Xem danh sách bundle npm run hot:list Liệt kê các bản cập nhật mới nhất, Bundle ID, Channel và trạng thái.

7 Xử Lý Sự Cố & Câu Hỏi Thường Gặp (FAQ)

1. App trên Simulator báo "Bạn đang dùng phiên bản mới nhất" dù vừa mới deploy? ▼
Nguyên nhân:
  • Lệch Target App Version (-t): Trong app.json phiên bản là 1.0.0. Nếu bạn deploy với -t 1.0.1 thì app 1.0.0 sẽ không nhận được bản vá. Khắc phục: Deploy lại với -t 1.0.0 hoặc -t "*".
  • Khác Channel: Kiểm tra xem app đang cấu hình channel nào (mặc định là production). Khi deploy phải cùng channel production.
2. Lỗi "Bundle signature verification failed"? ▼
Tình trạng: Trước đây thư viện @hot-updater/react-native trên iOS dùng thuật toán ký số không đồng bộ với CLI Node.js.
Giải pháp: Đã được vá triệt để trong dự án qua patch patches/@hot-updater+react-native+0.33.2.patch. Sau khi chạy npm install, lệnh postinstall: patch-package sẽ tự động áp dụng bản vá chuẩn RSA-SHA256 cho iOS.
3. Sau khi cập nhật xong có cần build lại native không? ▼
Không cần! Bản chất của Hot Update là chỉ cập nhật mã JavaScript và Assets (hình ảnh, fonts). Người dùng chỉ cần mở lại app là có ngay tính năng mới.
Lưu ý: Chỉ cần build lại native khi bạn thêm/sửa một thư viện có mã native (Objective-C/Swift/Java/Kotlin) hoặc đổi quyền trong Info.plist / AndroidManifest.xml.
4. Muốn test trên Android Emulator thì làm thế nào? ▼
Tương tự như iOS, trên Android bạn build bản Release lên Emulator: 
npx expo run:android --variant release
Sau đó deploy bản vá cho Android: 
npx hot-updater deploy -p android -c production -t 1.0.0 -f -m "Test Android OTA"
